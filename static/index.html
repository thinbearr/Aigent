Alerts are not answers.

Security tools in factories and power plants raise alarms, but a person still has to work out whether each one is real. Industrial Cyber-Arena lets a team of AI agents do that investigation, and one agent's only job is to doubt the others.

How an investigation works

1An alert fires

A detection tool flags something unusual in the plant.

2Blue investigates

It reads the logs through a controlled gateway and scores what looks suspicious.

3Critic challenges

It argues the other side and demands proof, such as a ticket or a valid signature.

4Forensics reconstructs

It builds the timeline and an evidence graph. Every link cites evidence.

5A human decides

The analyst approves the finding or sends it back. The system never has the last word.

What is simulated

  • Evidence weights are hand-set, so results show the mechanism, not real-world accuracy

Red Agent assessment

The Red Agent inspects the plant's configuration and lists weak settings, the same kinds of weakness reported in the Dec 2025 Poland energy-sector attacks (CERT Polska, 2026). It is read-only: it can look, not change anything.

Tool Gateway

Agents never touch the plant directly. Every request passes this gateway, which checks the agent's allow-list and the sandbox scope, then writes it to an audit log. The rules are enforced in code, not left to the model's judgement.
